# 战斗系统九维评价体系

一套基于行为锚定的战斗系统结构化评分框架，用于跨游戏、可复现的设计分析。用于帮助玩家理解游戏设计，帮助游戏改进。

## 使用目的

- 给游戏战斗系统做**结构化分析**
- 评价的是**设计结构**——输入深度、交互质量、轴自由度、角色耦合、Build空间、商业健康、内容演化、机制纵深、设计一致性
- 支持**跨游戏对比**
- 帮助玩家把体验感受翻译成结构，看懂游戏设计

## 🎯 核心设计理念

| 原则 | 说明 |
|------|------|
| **行为锚定** | 每个分数档对应「可观察的玩家/系统行为」，而非主观感受 |
| **结构优先** | 关注模块间如何连接，而非模块本身多华丽 |
| **防蹭分机制** | 机制存在 ≠ 机制有效。通过「架空检验」排除无效设计 |
| **跨游戏可比** | 同一维度对不同游戏使用同一套行为定义 |

> ⚠️ **免责声明**：本体系为结构评价工具，不替代实际游戏体验。高分 ≠ 好玩，低分 ≠ 不好玩。

## 🎲 九维速查

| 维度 | 一句话定义 | 评的是谁 |
|------|-----------|---------|
| ① 单角色深度 | 单个角色的输入边界与内部资源联动 | 单个可操控角色的指令系统 |
| ② 攻防交互质量 | 玩家与敌人的攻防互动是否构成战斗核心语言 | 敌人设计 + 交互收益结构 |
| ③ 轴管理自由度 | 战斗节奏是脚本化的还是可塑的 | 时间轴与决策树的结构 |
| ④ 角色耦合机制 | 多角色机制碰撞产生的化学反应深度 | 跨角色规则交互 |
| ⑤ Build 策略空间 | 角色/装备/技能选择的有效差异度 | 配置选择的策略价值 |
| ⑥ 商业健康度 | 付费设计对角色基础功能完整性的破坏程度 | 付费与机制的结构关系 |
| ⑦ 内容演化深度 | 新内容对旧内容的兼容性 | 长线运营中的内容迭代结构 |
| ⑧ 机制纵深 | 系统内部可挖掘的层次数量及层间反馈 | 机制层次与反馈回路 |
| ⑨ 设计一致性 | 战斗系统内部是否讲同一种语言 | 跨模块/跨角色的逻辑统一性 |

## 🚀 快速开始

### 方式一：完整阅读（推荐首次使用）
1. 打开最新版评分手册
2. 重点阅读 **第三章（全局防蹭分机制）** 和 **第四章（九维详细标准）**
3. 使用 **附录 B：评分记录模板** 完成你的第一次评分

### 方式二：5 分钟速评（快速上手）
1. 选择你要评价的游戏与版本
2. 逐维度回答：「该机制在最优策略中是否被实际利用？」
3. 对照行为定义确定整数档 → 小数校准 → 架空检验
4. 选择组合公式（F/A/B/C/D/E/G）计算加权得分
5. 一致性审查
